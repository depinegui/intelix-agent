# Manifesto de Nota de Compra

## Página 1

TELA NOVA DO MANIFESTO/CIÊNCIA/CONFIRMAÇÃO DAS OPERAÇÕES

”NOTAS DE COMPRA”

Parâmetro:

Se habilitado, aparece essa nova tela ...

Busca no Sefaz = Vai buscar as novas notas emitidas para a empresa, as quais
o cliente pode confirmar e dar ciência.

Busca local = Vai aparecer todas as notas já pesquisadas anteriormente,
pode-se validar pelo filtro.

## Página 2

O tempo de pesquisa entre uma e outra é de 1h - Após uma pesquisa há um
bloqueio interno, para que a MICROSYS não ganhe multa pelas pesquisas em
exagero.

Quando estiver com o download disponível no Sefaz, a caixinha vai estar
marcada com o “certinho” em download, pode-se então clicar direto em “Gerar
Notas Fiscais de Compra”.

1o Baixar as NF
2o Dar ciência
3o Depois de 1h aparecerá disponível as NFs para download
4o Dar entrada na NF

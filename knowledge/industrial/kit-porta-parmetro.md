# Kit Porta - Parâmetro

## Página 1

Habilita no pedido o campo de NF Kit Porta

Se quiser que saia Kit Porta como um item, só usar a primeira opção.

Se quiser que saia item por item discriminado usar a segunda opção.

Para denifir o produto “Kit Porta” precisa dentro do cadastro do produto, 1
produto estar com a fleg marcada ...

## Página 2

Percentual de Cheque:

Se o parâmetro do Kit Porta estiver ativo, dentro da NF ao importar o pedido, se
o mesmo possuir Percentual de Cheque, importa os produtos individualizados.
Se não possuir o percentual de cheque, importa o Kit Porta.

# MSYS Coletas

## Página 1

Tucano, VT de Videira utilizam ...

Login: msys

Senha: msys123

Este cliente pertence a: AMARRAR A FILIAL (Cadastrar o cliente principal, e
o cliente que será feito a coleta tbm).

Amarrar essas coletas no cliente principal.

EX: Prefeitura ... Amarrar todos os postos de saúde onde serão feitos as
coletas dentro da prefeitura.

Proprietário: Preencher para aparecer no contrato

Responsável: Preencher tbm, importante

Coletores: Quais seriam os motoristas que irão fazer essa coleta

Valor do contrato, FIXO: Não, valor é variável conforme a coleta. FIXO: Sim,
mesmo valor por mês.

Se for FIXO e der algum adicional, precisa lançar direto no financeiro o valor.

Grupo B, precisa colocar o valor no contrato, tem uma aba própria.

Aconselhável a fazer etiquetas, pedir para cliente colar na sacola/caixa que
será coletada, para assim ter um maior controle.

Ainda no contrato: Colocar os pontos de coleta.

Fluxo de transmissão: Envio do contrato para assinatura.

Verificar quando finalizar o contrato e gerar as coletas, excluir a própria
empresa, pois nela mesma não haverá coleta.

As vezes pode ser que duplique uma coleta, má conexão do aplicativo com
a Internet, mas é só excluir manualmente, gera o lançamento duplicado

## Página 2

com a mesma data e hora.

ABRIR O CONTRATO: Só se ainda não foi dado inicio nas coletas, pois se
abrir acaba excluindo todos os lançamentos já feitos, mesmo se baixado.

Relatório de coletas: Multiplicador por mês, “SIM” se for dentro de um mês,
mas se for abrangendo mais meses, colocar como “NÃO”.

Imprimir o relatório das coletas para lançar no financeiro, processo manual.

No aplicativo, não há filtro por coletores, todos veem as coletas de todos,
para assim algum motorista poder cobrir a ausência do outro.

Depois de baixado algum financeiro, só excluir a data de pagamento que
volta a ficar em aberto.

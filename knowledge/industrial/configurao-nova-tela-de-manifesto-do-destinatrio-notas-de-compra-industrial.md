# Configuração Nova Tela de Manifesto Destinatário Notas de

## Página 1

Compra. Industrial

A partir da versão 1.154.0. foi configurado uma nova tela para o Manifesto Destinatário de
Notas de compra.

Para configurar a Nova tela, você vai acessar o caminho:

Configurações → Configurações do Sistema

## Página 2

O caminho para acessar a tela permanece o mesmo:

Procedimentos → Compras → Manifesto Destinatário NF-e

## Página 4

Funcionamento do módulo seguindo o Passo a Passo

Passo 1: Clicar no Botão "Buscar NFe ́s Sefaz". Este processo vai listar todas as notas
emitidas contra o CNPJ da empresa e armazena-las em banco de dados.

Passo 2: Com a lista de notas que a Sefaz retornou, agora é possível fazer a manifestação.
Para isso selecione o documento que deseja manifestar. Selecione a opção (Ciência da
Operação ou Confirmação da operação), e clique em manifestar.

Passo 3: Após fazer a manifestação é necessário aguardar no mínimo uma hora para
conseguir baixar o xml e fazer a entrada da nota. Para este procedimento, clique
novamente no Botão "Buscar NFe ́s Sefaz". Com isso perceba que a coluna Download vai
ficar marcada, isso significa que o xml foi disponibilizado pela Sefaz e foi armazenado em
banco de dados.

Passo 4: Com o xml armazenado em banco de dados agora é possivel gerar a nota fiscal.
Para isso, marque os documentos que deseja gerar a nota e clique no botão "Gerar Notas
Fiscais de Compra".

OBS:

O botão "Filtrar" serve para listar as notas já baixadas da Sefaz e salvas em banco de dados,
de acordo com os filtros informados.

O botão "Salvar Danfe", serve para salvar um pdf em diretório pré-configurado, porem só
vai salvar se o documento já possuir o xml salvo, e a opção download estiver marcada.

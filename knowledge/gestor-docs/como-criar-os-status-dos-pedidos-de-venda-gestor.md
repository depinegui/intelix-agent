# Como criar os status dos pedidos de venda (GESTOR)

## Página 1

Acessar o menu de situações

No menu lateral:

Clique em Cadastros

Depois em Vendas

Clique em Situações

Isso abrirá a listagem de todos os status disponíveis no sistema

Criar uma nova situação

Na tela de situações:

Clique no botão ➕ Nova situação

Ou acesse uma situação disponível para edição

## Página 2

Preencher os dados da situação

Na tela de cadastro:

Campos principais:

Nome
Nome do status (ex: Aguardando aprovação, Em separação, Em entrega)

Tipo
Define o comportamento:

Pendente, Finalizado, Cancelado

Pendente-status inicial, nao poderá movimentar nada

Finalizado-status final, que pode ser movimentado estoques e
financeiros

Cancelado-cancelar os processos feitos com um pedido

Situação
Define se está:

Ativo ou Inativo

Situação inicial
Define se esse será o status padrão/inicial ao criar um pedido

Ícone
Ícone visual para facilitar identificação

Textos exibidos:

## Página 3

Texto botão
Nome da ação ("Finalizar pedido", "Cancelar pedido")

Texto auxiliar botão
Informação complementar (opcional) ao passar o cursor do mouse, um
texto pode ser exibido um texto

Aparência visual:

Cor do texto

Cor do fundo

Essas cores ajudam a identificar rapidamente o status dentro do sistema

Etapas vinculadas

Define em quais etapas essa situação pode ser utilizada, passar de uma
situação a outra, onde essa que está criando entrará nas opções

Etapas favoritas
Acesso rápido aos status mais usados

Comportamento da situação

Aqui está uma das partes mais importantes

Tipo de estoque gerado

Define se movimenta estoque (entrada/saída)

## Página 4

Estoque reserva, fica indisponível na tela do produto, mas não terá de
fato uma movimentação de estoque

Para visualizar isso, no módulo de estoque pode selecionar essa opção

Estorna movimentações

Usado em casos como cancelamento

Movimenta financeiro

Define se gera movimentações financeiras

Tipo fiscal

Define se permite gerar documento fiscal (NF-e / NFC-e)

Permissões

Controle o que pode ser feito nesse status:

Permite devoluções

Permite devoluções condicionais

Permite entrega parcial

Permite gerar assinatura

## Página 5

Permite impressões

Permite compartilhamento

Permite finalizar e novo

Situações finais vinculadas

Define o comportamento automático ao finalizar processos:

Situação final quando documento fiscal gerado

Situação final cancelamento

Situação final finalizado

Aqui você define para qual status o pedido vai automaticamente dependendo
da ação realizada

Salvar a situação

Após configurar:

Clique em Salvar

Como isso impacta o pedido de venda

Os status (situações):

Controlam o fluxo do pedido

Definem quando:

O estoque será movimentado

O financeiro será gerado

## Página 6

A nota fiscal poderá ser emitida

Permitem adaptar o sistema ao processo da empresa

Exemplo prático de fluxo

Um fluxo comum pode ser:

1. Pendente (status inicial)

2. Aguardando aprovação

3. Em separação

4. Em entrega

5. Finalizado

Ou, em caso de problema:

Cancelado

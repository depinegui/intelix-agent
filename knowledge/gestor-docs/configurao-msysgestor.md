# Configuração MsysGestor

## Página 1

📝Quais dados devo solicitar quando for fazer uma
Configuração no MsysGestor?

Daremos início à implantação da solução MSYS GESTOR para o cliente RAZÃO
SOCIAL- CNPJ. Para a configuração do sistema, solicitamos os seguintes
dados:

Documentos que o cliente emitirá:

( ) NF-e (Nota Fiscal Eletrônica);

( ) NFC-e (Nota Fiscal de Consumidor Eletrônica);

( ) NFS-e (Nota Fiscal de Serviço Eletrônica);

Configuração de Tributação para NF-e:

Qual é o CFOP para vendas dentro e fora do estado?

Qual é o CST para ICMS, PIS, COFINS e IPI para operações de vendas?

Qual é a alíquota de ICMS aplicada para vendas dentro e fora do estado?

Há algum benefício fiscal, redução de base de cálculo ou isenção de ICMS,
PIS, COFINS ou IPI?

Quais são as regras de cálculo do DIFAL para vendas interestaduais, se
aplicável?

Qual é a última numeração e série de NF-e emitida?

## Página 2

Configuração de Tributação para NFS-e:

Qual é o código de serviço utilizado para a emissão das NFS-e?

Qual é o ISS aplicado para os serviços prestados?

Qual é a tributação municipal da cidade do cliente?

Existe alguma particularidade local (isenções, alíquotas reduzidas)?

Qual é a última numeração e série de NFS-e emitidas?

RPS e Lote RPS iniciais a serem informados?

Configuração de Tributação para NFC-e:

Qual é o CFOP para vendas dentro e fora do estado aplicável às NFC-e?

Qual é o CST de ICMS, PIS e COFINS para operações de venda ao
consumidor final?

Qual é a última numeração e série de NFC-e emitida?

Precisamos do arquivo do certificado digital da empresa e a senha para todas
as configurações!

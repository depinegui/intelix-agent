# Manual de configuração para acesso do contador

## Página 1

Acessar as configurações do cliente: No sistema do cliente, navegar até a
seção de configurações gerais ->informações da empresa-> e clicar no botão
contador

Preencher as informações abaixo, que é solicitada ao contador da
empresa*

Geralmente mando uma mensagem explicando o que será feito...

‘‘Estamos realizando a configuração do sistema do contador e para que
possamos dar continuidade, precisamos que preencham as seguintes
informações”

## Página 2

Criar uma conta no sistema Gestor: A contabilidade precisa acessar a
plataforma e criar uma conta utilizando seu próprio e-mail e CNPJ. (os
mesmos usados nas informações vinculadas na tela do print acima) para que
ele acesse o sistema com a conta deles, e possam escolher quais das
empresas dos seus clientes ele quer acessar em caso de mais de um cliente*

Administrativo faz o vinculo da conta da contabilidade na conta do cliente com
o acesso delas

## Página 3

Após a contabilidade criar a conta e fazer o login, devemos ir às configurações
de usuário e alterar autoridade para "Contabilidade". Isso habilita
funcionalidades específicas do sistema para contadores.

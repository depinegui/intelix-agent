# Como gerar Ordem de Serviço (Gestor)

## Página 1

A Ordem de Serviço (OS) é utilizada para registrar, acompanhar e controlar a
execução de serviços prestados ao cliente, podendo envolver:

Serviços técnicos

Uso de produtos/peças

Controle de responsáveis (técnicos)

Geração de financeiro

Emissão de documento fiscal

Acessar o módulo de Ordem de Serviço

No menu lateral:

Clique em Serviços→ Depois em Ordem de serviço

Criar uma nova Ordem de Serviço

## Página 2

Na tela de listagem:

Clique em ➕ Nova ordem de serviço

Preenchimento da Ordem de Serviço

Dados principais

Cliente

Selecione um cliente já cadastrado

Ou utilize o botão + para cadastrar um novo

Data de abertura

Define quando a OS foi iniciada

Data de fechamento

Preenchida ao concluir o serviço (opcional no início)

Operação fiscal

Define como a OS irá se comportar fiscalmente

Ex: 1 - Venda

Informações do serviço

Objeto de serviço

Descrição breve do item/serviço

Ex: “Manutenção de computador”, “Revisão veículo”

Problema relatado

Descrição detalhada informada pelo cliente

Importante para histórico e execução técnica

Adicionar serviços e produtos

A OS permite trabalhar com:

Aba Serviços

Clique em + Adicionar serviço

Homologação Sicredi (Msys Gestor)

Cadastros > Finanças > Contas

API id: Código do Beneficiário + No Cooperativa (9 digitos)

API key: token gerado dentro do Portal do Desenvolvedor

API secret: Código de Acesso gerado pelo cliente no Internet Banking

API estação: No Cooperativa (4 digitos)

Homologação Unicred (Msys Gestor)

Apenas em ambiente de Produção

Cadastros > Finanças > Contas

API id: Identificador exclusivo fornecido pelo Unicred para o cliente, usado
para autenticação nas integrações via Web Service bancário.

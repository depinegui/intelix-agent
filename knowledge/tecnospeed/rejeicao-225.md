# Rejeicao 225

Fonte: TecnoSpeed
URL: https://atendimento.tecnospeed.com.br/hc/pt-br/articles/360012183534-NF-e-Como-resolver-a-rejei%C3%A7%C3%A3o-225-Falha-no-Schema-XML-do-lote-de-NFe

Problema:
A NF-e foi rejeitada por falha no schema XML do lote.

Possivel causa:
O XML pode estar mal formatado, com espacos entre tags, quebras de linha indevidas, caracteres especiais, nomes de tags incorretos ou versao de XML diferente da esperada pelo Web Service. O artigo tambem alerta para cenarios de homologacao em que campos de responsavel tecnico podem causar essa rejeicao.

Solucao:
Valide a estrutura do XML antes do envio, remova caracteres e formatacoes indevidas, confira nomes das tags e a versao do schema aceita pela SEFAZ. Se estiver em homologacao, revise tambem os campos de responsavel tecnico conforme a orientacao do artigo.
